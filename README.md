# 💸 FinCoach

**FinCoach** is a beginner-friendly finance app designed to help young adults make smarter financial decisions before it’s too late. Our goal is to make learning about money simple, interactive, and engaging.

---

## 🚀 What is FinCoach?

FinCoach is an app that combines **financial education, tracking tools, and interactive simulations** to help users understand how their everyday choices impact their future.

Our main highlight is a **life simulation experience** where users go through real-world scenarios and see how their decisions affect their finances over time.

---

## 👥 Who is it for?

FinCoach is built for:

* Young adults starting their financial journey
* Students learning about money management
* Anyone who wants to make better financial decisions early in life

---

## 🧩 Features (Planned)

* 📚 **Lessons**
  Simple, easy-to-understand financial education content

* 🎮 **Interactive Life Simulation (Main Feature)**
  Experience real-life scenarios (education, career, spending, etc.)
  → Make decisions
  → See how they impact your future finances

* 🧠 **Situation Helper**
  Get guidance on real-life financial decisions

* 🎯 **Games & Challenges**
  Learn finance through fun and interactive mini-games

* 📊 **Finance Tracking (Future)**
  Tools to help users monitor and manage their money

---

## 🛠️ How to Run the App

Follow these simple steps:

1. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

2. Run the app:

   ```
   streamlit run app.py
   ```
